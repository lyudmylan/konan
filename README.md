# konan

An agentic production-incident investigator built as Claude Code skills — the on-call
agent (from Hebrew word konan, כונן - being on-call) for your services. It investigates read-only, cites evidence for every
claim, and is measured by a seeded-fault eval harness before it is believed.

**Status: private bootstrap, pre-v0.1.** The repo flips public at v0.1, together with
the first eval scorecard.
